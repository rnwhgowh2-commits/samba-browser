# 삼바브라우저 개발 내용 — 2026-10-25

이 문서는 현재 PC 개발본을 GitHub `samba-local` 브랜치에 보관하는 기준으로 작성했다. 화면 구성과 소스 코드를 대조했으며, 기능이 구현된 범위와 별도 연결이 필요한 조건을 함께 적었다. 기본 `master`에는 다른 개발 이력이 있으므로 이 게시에서 덮어쓰거나 강제 병합하지 않는다.

## 현재 개발본 받기

```powershell
git clone --branch samba-local https://github.com/sbk0674-web/samba-browser.git
cd samba-browser
powershell -ExecutionPolicy Bypass -File .\scripts\setup-mcp.ps1 -StartBrowser
```

Node.js 20 이상·pnpm·Python 3.11 이상이 필요하다. 위 설치기는 Claude Code와 Codex 모두에 MCP를 등록한다. 최초 등록 후 각 클라이언트에서 MCP를 다시 연결하거나 새 세션을 연다. 앱의 AI 구독 로그인·API 키·동기화 계정은 각 PC에서 별도로 연결한다.

## 업로드 범위

로컬 `samba-local`의 기존 커밋과 스냅샷 시점의 미커밋 실행 소스·테스트·문서를 포함한다. 개발이 계속되는 공유 폴더 대신 별도 작업 폴더에서 스냅샷을 검증하고 커밋한다. 빌드 결과물·개인 탭 스트레스 기록·`.env`·키마스터 DB·토큰·사용자 MCP 설정·가상환경·의존성 폴더는 제외한다.

## 검증 기록

| 검사 | 결과 |
|---|---|
| 메인·프리로드 TypeScript | `tsc --noEmit -p tsconfig.node.json --composite false` 통과 |
| 화면 TypeScript | `tsc --noEmit -p tsconfig.web.json --composite false` 통과 |
| Electron 배포 빌드 | `electron-vite build` 메인·프리로드·화면 모두 통과. `.env` 없이 별도 검증 폴더에서 실행 |
| 브라우저 전체 Vitest | 234개 파일 통과·1개 건너뜀, 테스트 3,193개 통과·2개 건너뜀 |
| MCP 설치기 | Python unittest 17개 통과 |
| 세션 관리자 | Node 테스트 18개 통과 |
| 주문처리 하네스 전체 | 1,012개 중 1,010개 통과·2개 실패. 실패 2개는 배송 연락처 입력의 계정 라벨 인자가 추가된 이전 동작을 기대값에 반영하지 않은 항목이었음 |
| 하네스 실패 보완 후 재검증 | 기대값 2개를 보완하고 구매 에이전트 테스트 84개 통과. 다른 하네스 테스트는 위 전체 실행 결과를 사용하며, 전체 1,012개를 보완 뒤 다시 실행하지는 않음 |
| 업로드 파일 점검 | 스냅샷 소스 1,006개에서 비밀키 패턴·2MB 초과 파일 탐지 없음. 추가한 정리 문서와 테스트 보완도 게시 전 검사 |

이번 검증 과정에서는 브라우저 테스트의 누락된 `withFront` 모형, 정렬 기대값, 시간 부하에 좌우되던 커서 수집 테스트도 보완했다. 커서 테스트는 개수 상한 4,000개와 시간 예산 초과 시 중단을 나누어 검사한다. 앱의 구매·보안 동작은 이 테스트 보완을 위해 바꾸지 않았다.

환경의 `pnpm` 실행기가 자동 의존성 재설치를 시도하고 비대화형 실행을 거부해, 설치된 Node 실행 파일과 각 도구의 CLI로 동일한 타입 검사·빌드·테스트를 실행했다. 하네스는 별도 검증 폴더에서 `uv run --frozen --extra dev --extra desktop pytest`로 실행했다. 빌드 산출물·가상환경은 게시에서 제외한다.

자동 테스트·빌드는 코드 검증이며 모든 사이트의 로그인·구매·알림 전송을 실서비스에서 실행했다는 의미는 아니다.
