# 삼바브라우저 탭 전환 오류 개선 세션 (2026-10-25)

- 대상 세션: 삼바브라우저 탭 전환 오류 개선.
- 변경: Electron 42.9.2 고정, Node.js 22.12 이상, 사용자 화면을 가리지 않는 뒤 탭 캡처, 빈 캡처 오류 처리, OCR 캡처 경로 통일, 재시작 시 현재 설치 엔진 사용.
- 세션에서 확인: 관련 자동 검사 211개, 브라우저 유지 도구 검사 15개, 타입 검사와 빌드 통과. 실제 앱 최대 66개 탭·4개 레인에서 캡처 49회 성공.
- 남은 확인: 물리 Escape 입력으로 전경 버튼의 최종 검증 중단. 일부 금고 동기화 복호화 경고 추가 확인 필요.
- 상세 이력: [실행방법](실행방법.md)의 탭 전환 개선·추가 개선 기록.

- 삼바 본체의 `tools/browser_keeper/keep_browsers.py` 변경은 통합 저장소에 함께 보관한다.
